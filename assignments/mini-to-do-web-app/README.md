# 📘 Assignment: Mini To-Do Web App

## 🎯 Objective

Build a small interactive to-do list web app using HTML, CSS, and JavaScript. Students will practice user input, DOM manipulation, event handling, and basic data storage while creating something useful and easy to test in the browser.

## 📝 Tasks

### 🛠️ Build the App Layout

#### Description
Create the user interface for a to-do list with an input field, an add button, and a list that displays each task.

#### Requirements
Completed program should:

- Display a title such as "My To-Do List"
- Include an input field where a user can type a task
- Include a button to add a new task
- Display empty and filled task states clearly in the browser

### 🛠️ Add Interactivity

#### Description
Allow the user to add tasks, mark tasks as complete, and remove tasks from the list.

#### Requirements
Completed program should:

- Add a new task when the user submits text from the input field
- Prevent blank tasks from being added
- Mark a task as complete when clicked or toggled
- Remove a task when the user chooses to delete it
- Visually distinguish completed tasks from incomplete ones

### 🛠️ Save and Polish

#### Description
Improve the app so it feels more complete by saving tasks between refreshes and adding a small finishing touch.

#### Requirements
Completed program should:

- Save tasks so they remain after refreshing the page
- Load saved tasks when the app opens
- Show a clear message or style when the list is empty
- Include at least one additional improvement such as filtering, a task count, or a clear-all button
